# Planes archivados

Esta carpeta conserva planes, specs y listas de tareas de fases anteriores del simulador.

Estos documentos son historicos: sirven para trazabilidad del desarrollo, pero no deben tratarse como planes vigentes. La planificacion activa esta en los documentos situados directamente en `docs/plans/`.

Antes de reutilizar cualquier criterio de esta carpeta, debe contrastarse con:

- `docs/01_principios_tfg.md`
- `docs/02_requisitos_ingenieria_simulador.md`
- `docs/03_criterios_ingenieria_software.md`
- `docs/simulador/`
- `docs/reviews/auditoria_sintesis_multivista.md`
