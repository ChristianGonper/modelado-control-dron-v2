# Ficha de diagrama: marcos ENU y FRD

## Intención
- **Pregunta que responde:** ¿Qué dirección tienen los ejes y el empuje?
- **Mensaje principal para el lector:** mundo usa ENU, cuerpo FRD y el empuje actúa en $-z_B$.
- **Apartado de la memoria:** 3.1.
## Contenido
- **Elementos representados:** cuadricóptero nivelado, tríadas ENU/FRD y vector de empuje.
- **Relaciones y jerarquía visual:** marcos superpuestos con orígenes y ejes etiquetados.
- **Información que debe quedar fuera:** ángulos o escalas no implementados.
- **Pie sugerido:** Marcos de referencia empleados por el simulador. El sistema mundo usa la convención ENU y el sistema cuerpo la convención FRD; el empuje total se aplica en dirección opuesta al eje vertical del cuerpo.
## Convenciones y fuentes
- **Marcos, símbolos y unidades:** $x_W$ Este, $y_W$ Norte, $z_W$ arriba; $x_B$ delante, $y_B$ derecha, $z_B$ abajo; fuerza [N].
- **Colores, patrones y etiquetas:** cada eje combina color y letra.
- **Datos, código o bibliografía de procedencia:** `core/frames.py`, `core/attitude.py`, pruebas ENU/FRD.
## Reproducción
- **Formato y archivo fuente:** Script Python/Matplotlib `FIG-002.py`.
- **Herramienta y versión:** Python 3 (ejecutado en entorno `uv`).
- **Prompt, código o pasos manuales:** El script calcula las transformaciones 3D reales de los sistemas de coordenadas. El sistema mundo $\mathcal{W}$ representa la convención ENU (mano derecha) y el sistema cuerpo $\mathcal{B}$ la convención FRD (mano derecha), conectando ambos mediante el vector de posición $\mathbf{r}_{WB}$. Muestra el cuadricóptero en 3D real rotado y el vector de empuje $\mathbf{T}$ en dirección $-z_B$.
- **Comando de generación o exportación:** `uv run python TFG_Memoria/Figuras/diagramas/FIG-002.py`
- **Archivo incluido en LaTeX:** `Figuras/diagramas/FIG-002.pdf`
