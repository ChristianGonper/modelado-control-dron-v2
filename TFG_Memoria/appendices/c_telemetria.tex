Las figuras de este anejo no se emplean como prueba cuantitativa principal. Su
función es mostrar el tipo de evidencia visual que se inspecciona después de una
simulación cerrada y dar contexto a las métricas agregadas del capítulo de
resultados. A diferencia de una ejecución manual aislada, las telemetrías usadas
en este anejo proceden del dataset clásico consolidado:
\texttt{data/classic\_dataset/v1/results}. Por tanto, corresponden a los PD
expertos congelados que alimentan las fases de entrenamiento, validación y
prueba. Al final se añade un ejemplo de \texttt{results\_transfer} para ilustrar
la transferencia cruzada de esos mismos PD.
