El simulador representa el cuadricóptero como un cuerpo rígido con seis grados de libertad. La posición y velocidad lineal se expresan en el marco inercial local \(\frameW\), con convención ENU. Las magnitudes de cuerpo se expresan en el marco \(\frameB\), con convención FRD.

La cinemática y dinámica se desarrollarán a partir de las ecuaciones de Newton–Euler, usando cuaterniones para representar la orientación. Este apartado incluirá la ecuación traslacional, la ecuación rotacional, el modelo de actuadores, el mezclador de rotores, las saturaciones y las perturbaciones consideradas.
